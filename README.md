# ABC Executive Summary & Profitability Dashboard

An interactive Microsoft Excel dashboard for analyzing sales performance, revenue trends, and business profitability.

## 📊 Dashboard Preview

![ABC Executive Summary and Profitability Dashboard](Sales%20Dashboard.jpeg)

## 📌 About the Project

This project uses Microsoft Excel to transform sales data into an interactive dashboard that summarizes business performance. It combines key performance indicators (KPIs), charts, and interactive slicers to help users explore revenue, profitability, and sales distribution.

The dashboard provides a consolidated view of monthly performance and comparisons across countries, sales channels, regions, product categories, and quarters.

## 🎯 Key Performance Indicators

- **Total Revenue:** $645,223.18
- **Total Gross Profit:** $296,384.25
- **Gross Profit Margin:** 45.94%
- **Total Units Sold:** 6,698
- **Total Orders:** 2,707
- **Cost of Goods Sold (COGS):** $348,838.93

## 📈 Dashboard Features

- **Monthly Revenue and Profit Analysis:** Tracks changes in revenue and gross profit throughout the year.
- **Country-wise Revenue Analysis:** Compares revenue across countries.
- **Revenue Share by Channel:** Visualizes the contribution of different sales channels.
- **Region-wise Comparison:** Compares performance across regions.
- **Geographical Revenue Map:** Displays revenue distribution across countries.
- **Interactive Slicers:** Filter results by product category, country, and quarter.
